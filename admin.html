Firebase bağlantısı

Yapılandırılmadı

Firebase web yapılandırmanı yapıştır; sonuçlar Firestore'daki results koleksiyonuna yazılsın. Yapılandırma yokken site localStorage ile çalışmaya devam eder. Adım adım kılavuz: FIREBASE.md · Firebase Konsolu

Güvenlik notu: Firebase web anahtarı herkese açıktır, gizli değildir. Asıl koruma Firestore güvenlik kurallarıyla sağlanır. Kılavuzdaki kuralları kullanmadan yazma iznini açık bırakma.

Firestore güvenlik kuralları (örnek)

Konsol → Firestore → Rules bölümüne yapıştırabilirsin.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /results/{doc} {
      allow create: if request.resource.data.keys().hasAll(
        ['name','schoolNo','score','correct','total','percent']
      );
      allow read, update, delete: if false;
    }
  }
}
